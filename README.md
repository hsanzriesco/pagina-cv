# Portfolio / CV web — Héctor Sanz

Web CV pública, responsive y sin dependencias de JavaScript.

## Archivos
- `index.html` — estructura y contenido.
- `style.css` — diseño visual responsive.
- `script.js` — pequeñas animaciones de entrada.

## Cómo usarla
1. Abre `index.html` en el navegador para probarla.
2. Para publicarla en GitHub Pages, sube los tres archivos al repositorio y activa Pages.
3. Para Vercel, importa el repositorio y despliega como sitio estático.

## Nota
El contenido se ha creado a partir del CV proporcionado. La dirección postal completa del PDF no se ha incluido en la web pública; se muestra únicamente Valladolid, España.
